# 連続レッスンと初回導線の設計

## 背景

公開版では、読みモードで一文字の花を咲かせても、状態機械が次文字へ進んだ直後に画面だけが庭へ戻る。また初回は、説明のないスピーカーとじょうろを順番に押さないと「あ」の教材へ到達できない。どちらも3歳児の学習ではなく、次の操作を推測させる負荷になっている。

## 世界観辞書

- 背景: 朝のひらがなの庭
- 教材: 厚みのあるクリーム紙
- 線と文字: 濃藍のクレヨン線
- 成功: 読めた文字の花
- ホーム: いつでも戻れる庭
- 禁止: 意味を説明しない単独アイコン画面、成功直後の自動ホーム帰還、試験・点数・時間制限

## 画面と状態遷移

### 初回

保存読込中だけloadingを表示する。新規進捗なら、その後は直接「あ / intro」を表示する。introの「はじめる」を押すと、現在文字をseenにし、shapeMatchへ即時遷移する。同じユーザー操作から`AudioGuide.unlock()`を開始し、準備完了時点でまだ同じshapeMatchなら案内を読み上げる。rejectまたはvisual-onlyなら追加画面を出さない。

### 一文字完了後

- 読みモード、非行末: 次文字introを同じLessonScreenで表示する。
- よむ・かく、書字未完: 最初の未完書字段階を表示する。
- よむ・かく、書字完了または「あとで」、非行末: 次文字introを表示する。
- 行末: RowReviewScreenへ進む。復習完了後、46文字未満なら次文字introへ進む。
- 46文字完了: 文字の庭を表示し、既存CTAからことばの庭へ進む。

`selectRoute()`は保存再開時の庭導線に使い続ける。レッスン中のイベント結果は、`rowReview`、46文字完了、通常の次文字を明示的に分け、未読文字を理由に庭へ潰さない。

## 音声と失敗時の動作

初回CTAは音声Promiseを待たず画面遷移する。音声準備の完了通知は、文字・段階・request ID・mount状態を再確認してから読み上げる。古い文字や庭へ戻った後の音声は再生しない。speakerは従来どおりunlockと再生を再試行できる。

## 受け入れ条件

- 新規起動で、soundGate/wateringではなく「あ / intro」が表示される。
- 初回「はじめる」でshapeMatchへ進み、unlock rejectでも停止しない。
- 読みモードの「あ」reward後に「い / intro」が表示され、庭は表示されない。
- よむ・かくのreward後は書字へ進み、「あとで」の後に次文字introが表示される。
- 「お」完了後は行復習、行復習後は「か / intro」へ進む。
- 「ん」の行復習完了後は文字の庭へ戻り、ことばの庭CTAを表示する。
- 家で庭へ戻った後、同じ文字・段階を再開できる。
- 390x844と844x390で教材、CTA、家が重ならず、主要CTAは64px以上ある。
- 公開前の全テスト、型、Lint、Pages buildが通る。

## 非対象

- 行復習の内容・選択肢数の変更
- 保護者設定の項目追加
- 音声合成エンジンの変更
- 庭や単語コースの再設計

## リスクと対策

- 音声unlock完了が遅れて別画面を読み上げる: request IDと現在stageを再確認する。
- 連続進行で行復習を飛ばす: 非行末、行末、46文字境界を統合テストで分ける。
- STARTを通らずseenが保存されない: 初回intro CTAでseenとshapeMatchを一つのユーザー結果として検証する。
- reset後だけ旧gateへ戻る: reset統合テストで「あ / intro」を確認する。

## 性能目標

- 「はじめる」からshapeMatchのDOM更新は音声準備を待たず1 frame相当で開始する。
- 既存のCanvas 30fps上限、画像遅延読込、PWA容量を変えない。
